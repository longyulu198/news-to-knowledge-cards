# news-knowledge-extract

## 1. 项目解决什么问题

读了一篇文章或新闻后，知识点往往散落在长文里，难以提取、整理、梳理和复盘；手动做笔记又容易重复、啰嗦或漏掉重点。本项目提供一个可复用的 Skill，把文章自动转成凝练、连贯、可直接复习的知识点卡片。

## 2. 主要功能

- 输入：用户直接粘贴的文章正文，或本地 `.md` / `.txt` 文件路径
- 输出：至少 5 张知识点卡片；原文信息不足时只输出能支撑的数量，并在末尾说明，绝不凑数
- 每张卡片包含：标题、核心知识、简明解释、这个知识点能解决什么问题（它出现的意义）、例子或自测问题
- 只提取原文有依据的内容：不编造、不补充原文没有的事实、删除重复与套话
- 卡片按事实与背景 → 机制或因果 → 数据与效果 → 限制与风险 → 应对或建议的顺序排列，逻辑连贯
- 暂不支持：网页抓取、PDF、Anki 和图形界面

## 3. 安装方法

1. 下载或克隆本项目。
2. 将 `news-knowledge-extract/` 整个目录复制到你的 Agent skills 目录。Codex 通常为 `~/.codex/skills/` 或项目内的 `.codex/skills/`。
3. 确认目录中存在 `SKILL.md` 和 `agents/openai.yaml`，重启 Agent 后即可使用。

## 4. 使用方法

直接粘贴正文，并说明要提取知识点：

```text
请把这篇文章整理成知识点：

缓存把算好的结果放在读取更快的存储里……
```

也可以给出本地文件路径：

```text
请用 news-knowledge-extract 整理 ./article.md 的知识点。
```

Skill 会直接输出卡片，不加前言或过程说明。若传入网页链接、PDF 或要求生成 Anki 卡片，Skill 会说明不支持并请你改用粘贴文本或 Markdown/TXT 文件。

## 5. 输入输出示例

**输入**

```text
缓存把算好的结果放在读取更快的存储里。下次相同请求命中缓存时，系统直接返回结果，不再访问数据库，页面响应因此更快。一篇热门文章一分钟被请求一万次，没有缓存时数据库要处理一万次相同查询，有缓存时可能只需处理一次，其余由缓存响应。数据更新后旧缓存可能残留，用户会看到过期内容，常见做法是设置过期时间或在数据变更时主动清除。缓存放在浏览器里可以避免网络请求，放在服务器前面可以减少数据库访问，两者常一起使用。
```

**输出**

```markdown
### 1. 缓存用已算好的结果加快响应
- 核心知识：缓存把算好的结果放在读取更快的存储里，命中后直接返回，不再访问数据库。
- 简明解释：相同请求到来时先查缓存，找到就用这份结果返回；因为读取比数据库查询快，页面响应更快。
- 这个知识点能解决什么问题（它出现的意义）：解释加入缓存后页面为什么打开更快，以及加速发生在哪一步。
- 例子或自测问题：自测：缓存命中时系统返回结果的过程与首次访问有何不同？

### 2. 缓存减少数据库的重复查询
- 核心知识：缓存能大幅减少数据库的重复查询次数。
- 简明解释：热门文章一分钟被请求一万次时，无缓存需处理一万次相同查询，有缓存可能只需处理一次，其余由缓存响应。
- 这个知识点能解决什么问题（它出现的意义）：说明缓存在加速之外的另一价值——减轻数据库压力。
- 例子或自测问题：原文例子：热门文章一分钟被请求一万次，有缓存时数据库可能只需处理一次相同查询。

### 3. 旧缓存会导致过期内容
- 核心知识：数据更新后旧缓存可能残留，用户会看到过期内容。
- 简明解释：缓存不是永久正确的，因此原文给出两种应对方式：设置过期时间，或在数据变更时主动清除。
- 这个知识点能解决什么问题（它出现的意义）：消除“缓存会不会一直返回旧内容”的疑惑。
- 例子或自测问题：自测：数据更新后用户看到过期内容时，有哪两种常见应对办法？

### 4. 缓存位置决定省掉哪段开销
- 核心知识：浏览器缓存可以避免网络请求，服务器前面的缓存可以减少数据库访问，两者常一起使用。
- 简明解释：不同位置的缓存优化的是不同链路环节，原文指出选择取决于内容变化频率和是否涉及用户隐私。
- 这个知识点能解决什么问题（它出现的意义）：回答缓存该放在哪里、不同位置分别解决什么问题。
- 例子或自测问题：自测：想减少数据库访问应选哪种位置的缓存？想避免网络请求又该选哪种？

### 5. 缓存命中率决定加速效果
- 核心知识：若大部分请求找不到缓存，加速效果有限；命中率取决于内容是否被重复请求以及缓存容量是否足够。
- 简明解释：原文指出命中率是缓存是否有效的关键条件。
- 这个知识点能解决什么问题（它出现的意义）：解释为什么有的场景加了缓存却几乎没变快。
- 例子或自测问题：自测：什么情况下加了缓存加速效果仍然有限？命中率由哪两个因素决定？
```
